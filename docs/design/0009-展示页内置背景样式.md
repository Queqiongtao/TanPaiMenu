# 0009 展示页内置背景样式

- 状态：已实现（2026-10-06）
- 对应阶段：Phase 1 修订（展示页外观）
- 关联：`docs/design/0007-展示页背景图片.md`、`docs/design/0006-展示页紧凑布局与默认菜单.md`、`docs/architecture.md`

## 1. 背景与目标

0007 让店主能把自己的图片当背景，但「手边没有合适图片」时只能退回纯色底。店主希望开箱即有几个可用的背景样式，一次点选即可换成有质感的底色，同时不增加安装包体积、不牺牲菜名与价格的可读性。

目标：

- 内置 6 款中式餐饮暖色背景样式，在管理页设置弹窗内一次点选即生效。
- 全部由 Compose 代码绘制（渐变 + 光晕），不打包任何图片资源，APK 体积基本不变。
- 内置样式与自定义背景图并列单选、互相覆盖：任一时刻只有一种背景生效；都没有时回退 M3 纯色底（与 0007 未设置背景图的视觉一致）。
- 现有「背景蒙版不透明度」滑条对内置样式同样生效。
- 老版本升级后行为不变（已有自定义图仍显示自定义图），无需数据迁移。

## 2. 方案设计（含取舍）

### 2.1 样式定义（唯一真源）

`ui/theme/BackgroundStyles.kt` 定义 `BackgroundStyle(id, labelRes, gradient, glow)`，`BackgroundStyles.All` 是唯一样式清单，展示页绘制与管理页色卡预览共用同一份定义，避免两处配色漂移。

| id | 中文名 | 主渐变（左上 → 右下） | 中心光晕 |
| --- | --- | --- | --- |
| `warm_red` | 喜庆红 | `#B32C1B` → `#6E150C` | `#FFD9A0` 15% |
| `amber` | 暖橘 | `#D97A21` → `#8A3B0C` | `#FFE7B8` 18% |
| `caramel` | 焦糖 | `#B06E2C` → `#5A3010` | `#E8C08A` 15% |
| `rice_paper` | 米黄宣纸 | `#EAD6B2` → `#C6A87A` | `#FFFFFF` 20% |
| `sauce_red` | 酱红 | `#8A2620` → `#420E0B` | `#FFB27A` 12% |
| `bamboo` | 竹青 | `#6E8A4E` → `#33471F` | `#E6F0C8` 15% |

取舍：前 5 款为暖色系，`bamboo` 是唯一冷调点缀，避免 6 张色卡过于雷同；全部按「再叠默认 30% 白蒙版后仍好看」调色。真机实测：默认 30% 白蒙版会明显提亮并压缩色差，故配色整体比目标观感更深一档（首版偏淡，已加深）。光晕统一居中（用 `Brush.radialGradient` 的默认中心与半径），不做角落定位，以保持与绘制尺寸无关、无需测量布局。

### 2.2 绘制方式

- 主渐变：`Brush.linearGradient(colors, start = Offset.Zero, end = Offset.Infinite)`，随绘制区域自适应铺满，与屏幕比例无关。
- 光晕：`Brush.radialGradient(0f to glow, 1f to Color.Transparent)`，用 Compose 默认的居中中心与半径。
- 两层用链式 `Modifier.background(brush)` 叠绘，不需要 `drawBehind` 与尺寸测量。

### 2.3 存储与互斥

| 设置项 | key | 取值 | 默认 |
| --- | --- | --- | --- |
| 内置样式 id | `background_style` | 样式 id 或空 | 空（未选内置样式） |
| 背景图相对路径 | `background_image` | `images/<uuid>.jpg` 或空 | 空（未设置，0007 既有） |

互斥规则：

- 选内置样式：写 `background_style`，同时清空 `background_image` 并删除旧图文件。
- 选相册 / 拍照：写入 `background_image`，同时清空 `background_style`。
- 「恢复默认」：两者都清，并删除图片文件。
- 启动孤儿图清理与「恢复默认菜单」的保留集合仍只含 `backgroundImagePath`（样式不涉及文件），逻辑不变。

### 2.4 与蒙版、卡片的关系

- 白色蒙版层不变，统一叠在背景层之上，因此内置样式同样受蒙版滑条影响。
- 卡片半透明会让背景样式从卡片后透出，属预期效果，与 0007 一致。

### 2.5 备份口径

内置样式是设置项、不涉及文件，与蒙版、店名、卡片不透明度一致：不参与导出 / 导入，`backup.json` 仍为 `format 1`。

## 4. 边界与失败场景

| 场景 | 处理 |
| --- | --- |
| 未选样式且无自定义图 | 不渲染背景层，M3 纯色底，与旧版一致 |
| 样式 id 在当前版本不存在 | `byId` 返回 null，按未选样式处理，回退纯色底 |
| 自定义图文件被外部删除 | 与 0007 一致：`File.exists()` 为假，回退纯色底 |
| 选中样式后再选相册图 | 样式写入为空，色卡取消选中，自定义图生效 |
| 蒙版调到 80% | 内置样式接近纯白底，由店主自行判断 |

## 5. 测试与验收

- JVM 单测 `BackgroundStylesTest`：样式 id 唯一且非空、共 6 款、`labelRes` 唯一、每款渐变不少于 2 个色标、`byId(null)` 与未知 id 返回 null。
- 真机手工验收：6 款逐个点选即时生效、选中态正确；蒙版 0% / 30% / 80% 对内置样式同样可见；选相册图后样式取消选中且自定义图生效；「恢复默认」回到纯色底；冷启动后样式保持；「恢复默认菜单」后样式仍在；12 道一屏不滚动无回归。
- 体积与构建：`gradlew assembleDebug` 与 `testDebugUnitTest` 通过，无新增资源文件，APK 体积无明显变化。
