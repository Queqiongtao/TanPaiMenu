# 0003 平板运行形态与门禁

- 状态：已实现（Phase 1；门禁能力于 M8 修订，见 `docs/design/0017`）
- 对应阶段：Phase 1
- 关联：`docs/architecture.md`、`docs/PLAN.md` 第 6 节 Phase 1

## 1. 背景与目标

平板摆在摊位上长期运行且顾客可触屏，需要明确开机自启、常亮、全屏与退出 / 管理门禁行为，避免顾客误退出或误改菜单。

## 2. 运行形态

- 开机自启：监听 `BOOT_COMPLETED` 启动展示页；同时保留桌面图标入口。
- 常亮：展示页持有 `FLAG_KEEP_SCREEN_ON`；仅展示页生效，管理页可正常熄屏。
- 沉浸式：展示页隐藏状态栏与导航栏；从边缘临时唤出后自动隐藏。
- 默认桌面（Home）：API 24 无法编程设置默认 Home。应用内提供引导步骤（跳系统「默认应用 → 主屏幕」设置），并提供「验证 Home 键拦截」检查项。
- 兜底：未设为 Home 时，仍以沉浸式 + 全屏 + 长按退出保护降低误退风险。

## 3. 门禁与退出

- 展示页长按店名 2 秒弹出 PIN 输入，验证通过才进入管理页。
- PIN：4-6 位数字，加盐 SHA-256 存储；连续 5 次失败锁定 60 秒。
- 退出应用：管理页内显式「退出到桌面」入口 + PIN 二次确认。
- 密码管理（M8 修订）：管理页设置弹窗可「修改管理密码」（校验旧码）与「关闭密码保护」（校验旧码 + 二次确认）。
- 忘记 PIN（M8 修订）：输入弹窗内「忘记密码」长按 3 秒 → 二次确认 → 清除密码并强制设置新密码后进入管理页，菜单与图片不受影响；不再需要清除应用数据（见 `docs/design/0017`）。

## 4. 边界与失败场景

- 厂商 ROM 限制自启：引导用户把应用加入自启动白名单，帮助中给出检查步骤。
- 系统栏被其他应用唤起：返回展示页后重新进入沉浸式。
- 暴力尝试 PIN：失败计数达 5 次即锁定 60 秒，期间不接受输入。

## 5. 测试与验收

- 重启平板后自动进入展示页。
- 连续放置数小时不熄屏；顾客乱点无法退出到桌面。
- 长按 2 秒弹出 PIN；连续错误 5 次后锁定 60 秒。
- 未设置默认 Home 时，返回键与 Home 键均无法离开展示页（在可拦截范围内）。

## 6. 未决事项

- 是否在管理页也禁用截图（当前不做）。

## 7. 实现位置与验证结果（Phase 1）

- 沉浸 / 常亮 / 退出到桌面：`kiosk/Kiosk.kt`（`KeepScreenOn` 组合项、`exitToHome` 解析并跳到系统桌面、`openHomeSettings`）、`MainActivity.kt`（`onCreate` / `onResume` / `onWindowFocusChanged` 重设沉浸）。
- 开机自启：`kiosk/BootReceiver.kt` + `AndroidManifest.xml`（`RECEIVE_BOOT_COMPLETED`、HOME intent-filter）。
- 门禁：`ui/TanPaiMenuApp.kt`（长按店名 2 秒 → 设 / 验 PIN）、`data/PinManager.kt`、`data/SettingsStore.kt`（自启开关、PIN 哈希与盐）。
- 真机验证：重启后自启并停在展示页；屏保 15s 门限下长时间不熄屏；切到系统设置返回后仍为沉浸式；退出到桌面直达 `com.wisky.launcher`（不再弹选择器）；沉浸态下系统栏隐藏。

### 实现位置与验证结果（门禁修订，2026-10-07）

- 组件：`ui/admin/AdminDialogs.kt` 的 `HoldToTriggerButton` / `PinChangeDialog` / `PinDisableDialog`；`ui/TanPaiMenuApp.kt` 的忘记密码通道（`FORGOT_HOLD_MS = 3_000`、`pinSetupForced`）；`ui/admin/AdminScreen.kt` 设置弹窗「管理密码」区块；`data/PinManager.clearPin()`。
- 风险：免密重置通道削弱门禁（知情者可重置后改价），用「长按 3 秒 + 二次确认 + 强制重设 + 日志留痕」压低误触与滥用概率；取舍理由见 `docs/design/0017` 第 2.3 节。
- 验证：仪表 `data/PinManagerTest` 通过；真机走通「忘记密码长按 → 二次确认 → 强制设置新密码 → 新码进入管理页」与「关闭密码保护 → 长按店名直接进入」；关闭后 `shared_prefs` 中不再有密码哈希与盐值。
