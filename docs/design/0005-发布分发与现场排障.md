# 0005 发布分发与现场排障

- 状态：已实现（Debug APK 分发；正式 Release 签名待定）
- 对应阶段：Phase 4
- 关联：`docs/PLAN.md` 第 6 节、`docs/design/0003-平板运行形态与门禁.md`、`docs/design/0004-图片处理与数据备份.md`

## 1. 背景与目标

明确 v1 成品的构建产物、签名、分发、升级方式，以及摊位现场的排障手段。本文是构建、打包与安装流程的详细说明；README 只保留快捷命令。

## 2. 工具链与构建入口

- 环境自检：`scripts\doctor.bat`，只读检查 JDK 17、Android SDK、Gradle、wrapper 与 PATH。
- 首次配置或修复：`scripts\setup-toolchain.bat`；只补 PATH / wrapper 配置时使用 `-ConfigureOnly`。
- 标准脚本：`scriptsuild-and-install.bat`，内部调用 `gradlew.bat assembleDebug --no-daemon`，构建成功后安装到 `adb devices` 中的第一台在线设备，并检查启动后的 crash 日志。
- 只构建：`scriptsuild-and-install.bat -SkipInstall`。
- 直接调用 wrapper：

```powershell
$env:JAVA_HOME = 'C:\Program Files\Eclipse Adoptium\jdk-17.0.20.101-hotspot'
$env:ANDROID_HOME = 'D:\Android\Sdk'
$env:ANDROID_SDK_ROOT = 'D:\Android\Sdk'
.\gradlew.bat :app:assembleDebug
```

构建参数与设备选择规则以 `scriptsuild-and-install.ps1` 为准，不要在文档或脚本中写死当前测试设备序列号。

## 3. 构建产物与签名

- 当前分发产物：`appuild\outputspk\debugpp-debug.apk`。
- Debug APK 使用 Android debug 签名，仅用于内部安装、摊位设备部署和多机验收。
- ABI：仅输出 arm64-v8a。
- 混淆：关闭 minify，保留 NanoHTTPD 相关反射行为。
- Release：`assembleRelease` 尚未配置正式 keystore 和签名流程，当前产物不能作为正式发布包。正式签名密钥的生成、保管、渠道选择与上架方式另行设计。

## 4. 安装与升级

- 单设备脚本：`scriptsuild-and-install.bat` 会自动选择第一台在线设备。
- 多设备：先 `scriptsuild-and-install.bat -SkipInstall`，再用 `adb -s <serial> install -r appuild\outputspk\debugpp-debug.apk` 分别安装到手机和平板。
- `install -r` 为覆盖安装，保留应用数据；卸载会清除数据。
- Room schema 变更必须提供 Migration 与迁移测试；schema JSON 入库 `app/schemas/`。
- 升级前如需保留菜单与图片，可在平板设置中导出备份；详见 `docs/design/0004`。

## 5. 测试

- JVM 单测：`.\gradlew.bat :app:testDebugUnitTest`。
- 真机仪表测试：设置 `ANDROID_SERIAL=<serial>` 后运行 `.\gradlew.bat :app:connectedDebugAndroidTest`，避免多设备并行互相干扰。
- 发版前至少执行：单测、Debug 构建、目标平板仪表测试和双机配对 / 编辑验收。
- Android 9+ 手机需要允许局域网明文 HTTP；当前通过 `AndroidManifest.xml` 的 `android:usesCleartextTraffic="true"` 实现，见 `docs/design/0019`。

## 6. 现场排障

- 应用日志：`TpLog` 写 `filesDir/logs/app-<date>.log`，保留最近 7 天。
- 一键收集：`scripts\collect-logs.bat` 导出 `device.txt`、`logcat.txt` 与 `app-logs/`，默认输出到 `dist\logs\<时间戳>\`。
- 设备未出现在 `adb devices`：检查 USB 数据线、USB 调试开关和授权弹窗。
- 手机连不上：确认同一网段；平板 IP 变化后重新输入地址；确认长期令牌和手机控制端状态。
- 忘记 PIN：按设计文档执行重置或清除数据；清除数据前先导出备份。

## 7. 实现位置与验证结果

- 构建脚本：`scripts/build-and-install.ps1`、`scripts/build-and-install.bat`。
- 工具链脚本：`scripts/setup-toolchain.*`、`scripts/doctor.*`、`scripts/device-precheck.*`。
- 日志脚本：`scripts/collect-logs.*`。
- 已验证：Debug APK 构建、单设备安装、Android 7 平板与 Android 16 手机分别覆盖安装、双机配对/编辑以及恢复默认菜单流程。
