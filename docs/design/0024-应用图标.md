# 0024 应用图标

- 状态：已实现（2026-10-07）
- 对应阶段：Phase 5（打磨）
- 关联：`docs/design/0023-手机端删除与展示设置.md`、`docs/architecture.md`

## 1. 背景与目标

应用此前**没有图标**：`AndroidManifest.xml` 未声明 `android:icon`，桌面与最近任务里用的是系统默认图标，与「大金馄饨」这个实际摊位完全认不出来。目标是给一个简单、扁平、小尺寸下也认得出的图标，并覆盖 Android 7.0（平板，无自适应图标）与 Android 14（手机，自适应图标）两种形态。

## 2. 方案设计（含取舍）

### 2.1 图形与配色

- 图形：白瓷碗 + 三只馄饨 + 两缕热气。碗与馄饨是「馄饨店」最直接的识别符号，且在小尺寸下仍是清晰色块。
- 配色沿用展示页内置样式「喜庆红」的色系（亮红 `#D8563E` → 暗红 `#92301E` 渐变底，米白 `#FAF7F0` 碗、`#FDEFD4` 馄饨），保证与 App 内视觉一致。
- 取舍：不放店名字形。原计划在图标里写「馄饨」二字，但矢量 drawable 不支持 `textPath`，而本机构建沙箱不允许向 `res/` 写入二进制位图（PNG），只能二选一；纯图形方案在 48dp 下辨识度更好，最终采用。

### 2.2 两套资源与遮罩

| API | 资源 | 说明 |
| --- | --- | --- |
| 26+ | `mipmap-anydpi-v26/ic_launcher.xml`、`ic_launcher_round.xml` | 自适应图标：`drawable/ic_launcher_background`（108dp 渐变铺满）+ `drawable/ic_launcher_foreground`（主体收在中央约 66dp 安全区） |
| 24–25 | `mipmap-anydpi/ic_launcher.xml`、`ic_launcher_round.xml` | 旧版图标：**自带红色圆底** + 同样的碗与馄饨 |

旧版图标必须自带圆底：Teclast T10（Android 7.0）的 Launcher 会对旧版图标做圆形遮罩，只画白色图形会被裁成一个白色剪影（真机实测踩过），加圆底后才是完整的圆形图标。

### 2.3 实现方式

全部用矢量 XML（`<vector>` + `<aapt:attr>` 渐变）实现，不引入位图：任意分辨率清晰、包体几乎不增、也不受本机沙箱无法写二进制资源的限制。

## 3. 接口与数据模型变化

无。仅新增 5 个图形资源，并在 `<application>` 上补 `android:icon` / `android:roundIcon`。

## 4. 边界与失败场景

- 无自适应图标的设备（API 24–25）：走旧版资源，已验证圆形遮罩下正常。
- 圆形图标：`android:roundIcon` 在两种 API 段都有对应资源，不会解析失败。
- 主题色与图标不一致：图标只用于桌面 / 最近任务，不影响应用内展示页配色。

## 5. 测试与验收

- 构建：AAPT2 通过（渐变背景、矢量路径、自适应图标 XML 均能编译）。
- 真机：
  - Teclast T10 / Android 7.0：桌面显示红底 + 白碗 + 馄饨（含圆形遮罩）。
  - 小米 24122RKC7C / Android 14：最近任务卡片显示同样的图形与红底渐变。

## 6. 未决事项

- 是否在图标里加入店名字形：需要引入位图（`mipmap-*/ic_launcher.png`）才能稳定渲染文字，当前不做。
- 是否提供自适应图标的单色（themed icon，Android 13+）变体：当前不做。
