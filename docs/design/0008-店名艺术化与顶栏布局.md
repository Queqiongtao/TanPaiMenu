# 0008 店名艺术化与顶栏布局

- 状态：已实现（2026-10-06）
- 对应阶段：Phase 1 修订（展示页外观）
- 关联：`docs/design/0006-展示页紧凑布局与默认菜单.md`、`docs/design/0007-展示页背景图片.md`、`docs/architecture.md`

## 1. 背景与目标

店名此前是 44dp 顶栏内的 28sp 淡紫胶囊，与 22sp 菜名层级接近，作为摊位招牌不够显眼。

目标：

- 店名放大到 48sp，成为整屏第一视觉焦点，并加入艺术化处理（渐变底、描边、投影）。
- 店名换用书法/手写风格字体（霞鹜文楷），与菜名的无衬线体拉开气质差异。
- 顶栏加高后仍保证「12 道菜一屏不滚动」与「分类胶囊不重叠」。
- 长按店名 2 秒进入管理的行为不变。

## 2. 方案设计（含取舍）

### 2.1 垂直预算

真机（Teclast T10 / 2560×1600 / density 426）应用区高约 601dp。

| 项 | 旧值 | 新值 |
| --- | --- | --- |
| 内容内边距 | 12dp | 12dp |
| 顶栏高度 | 44dp | 72dp |
| 顶栏与网格间距 | 16dp | 8dp |
| 卡片高度 | 68dp | 68dp |
| 网格行距 | 16dp | 12dp |
| 网格列距 | 16dp | 16dp |
| 网格底部留白 | 24dp | 24dp |
| 合计 | 596dp | 596dp |

网格 = 6×68 + 5×12 + 24 = 492dp；合计 12+72+8+492+12 = 596dp，仍剩约 5dp 余量，12 道一屏不滚动。

取舍：

- 只压缩行距（16→12dp）与顶栏间距（16→8dp）即可腾出 28dp，卡片高度与缩略图保持 68 / 56dp，菜名 22sp 可读性不变。
- 曾考虑把分类胶囊移到店名下方单独一行：顶栏将达 112dp，必须把卡片压到 64dp 才能一屏，代价大于收益，未采用。
- 曾考虑店名悬浮覆盖第一行卡片：会遮挡菜品，未采用。

### 2.2 招牌样式

- 胶囊：固定高 68dp、`RoundedCornerShape(50)` 胶囊形、水平内边距 20dp，垂直居中于 72dp 顶栏。
- 底色：`Brush.horizontalGradient`，`#5B3FD6 → #9257E8`。
- 描边：1dp `#59FFFFFF`（白色 35%）。
- 投影：`Modifier.shadow(elevation = 8dp)`，颜色 `#733A1E85`；自定义阴影色需 API 28+，本机 API 24 落回系统默认阴影色，渐变与描边不受影响。
- 文字：纯白 48sp / 行高 56sp，`maxLines = 1`。
- 限宽：沿用 `min(320dp, 顶栏宽 × 0.4)`，与右侧分类胶囊（≤30%）互不重叠。
- 配色集中在 `ui/theme/StoreNameColors.kt`，与 Material3 主题解耦（对齐 `StatusColors.kt` 既有做法）。

### 2.3 字号降档

店名可由店主任意输入。48sp 下 320dp 限宽约容纳 6 个汉字，因此按字数降档：

| 店名字数 | 字号 / 行高 |
| --- | --- |
| ≤ 6 | 48sp / 56sp |
| > 6 | 36sp / 44sp |

仍超出限宽时使用省略号（沿用旧行为）。判断按字符数，不区分全角半角。

### 2.4 店名字体

- 字体：霞鹜文楷（LXGW WenKai）Medium，SIL OFL 1.1。
- 使用裁剪后的 GB2312 常用字子集（一级 + 二级 6763 字，另加 ASCII 与常用中文标点，共 6897 字符），产物 `app/src/main/res/font/store_name_wenkai.ttf`（3.4MB）。
- 字表之外的生僻字运行期由系统字体回退，属预期行为。
- 保留字体名（RFN）：该字体的 OFL 声明了 RFN（'霞鹜'、'霞鶩'、'落霞孤鹜'、'LXGW'），其附加许可只覆盖「web font 交付」的子集、不含 App 内置，因此子集内部名称改写为 `TanPai Store Name`；版权与许可字段保持原样，许可文本归档到 `docs/third-party/LXGWWenKai-OFL.txt`。
- 字体族 `StoreNameFontFamily` 只用于店名；菜名、分类名与其余界面继续用 `ChineseFontFamily`（Noto Sans SC Bold），避免 22sp 下楷体可读性下降。
- 生成脚本：`scripts/fetch-store-name-font.ps1`（同名 `.bat` 为入口封装），下载源字体到 `.toolchain/fonts`（已 gitignore）后调用 fontTools `pyftsubset`，可重复生成。

## 4. 边界与失败场景

| 场景 | 处理 |
| --- | --- |
| 店名为空 | 回退显示 `app_name`，并按字数规则选字号 |
| 店名超过 6 字 | 降档到 36sp；仍超出限宽则省略号 |
| 店名含生僻字 | 该字回退系统字体，其余字仍为楷体 |
| API < 28 | 投影使用系统默认颜色，渐变与描边不受影响 |
| 分类数 > 1 | 分类胶囊靠右显示，与居中的店名限宽互不重叠 |
| 不执行字体脚本 | `res/font` 中的子集已入库，构建不依赖脚本；脚本仅用于更换字体版本或字表 |

## 5. 测试与验收

- 12 道仍一屏不滚动：第 6 行底部 + 底部留白合计不超过 601dp。
- 招牌几何：胶囊高 68dp、顶栏 72dp、文字 48sp，垂直居中。
- 渐变、1dp 描边、投影在真机可见；白字对渐变两端对比度不低于 3:1（大字 AA）。
- 字体隔离：店名为霞鹜文楷，菜名与分类仍为 Noto Sans SC Bold。
- 回归：长按店名 2 秒弹出 PIN；分类胶囊与店名不重叠；设置项与备份行为不受影响。
