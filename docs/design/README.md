# 设计文档索引

本目录存放每个功能的设计文档。规则见 `AGENTS.md` 第 2 节「文档先行与技术文档」。

## 命名与流程

- 命名：`NNNN-中文简述.md`，四位编号从 0001 起递增，不复用；示例 `0001-菜单列表页.md`。
- 流程：先在本文件登记 → 写设计文档正文 → 再开始写代码 → 代码完成后回填实现位置与验证结果。
