# 0012 展示页价格强调

- 状态：已实现（2026-10-06）
- 对应阶段：Phase 1 修订（展示页外观）
- 关联：`docs/design/0006-展示页紧凑布局与默认菜单.md`、`docs/design/0009-展示页内置背景样式.md`、`docs/design/0011-展示页默认外观与整数价格.md`、`docs/architecture.md`

## 1. 背景与目标

卡片底不透明度降到 15% 后，卡片本身几乎透明，18sp 的紫色价格和菜名混在一起，顾客扫一眼不容易先看到价格。店主希望价格更显眼。

目标：

- 价格成为卡片里除菜名之外最醒目的元素：淡色圆角胶囊底 + 喜庆红大字。
- 价格数字与单位分层：数字 22sp（与菜名同级），单位 13sp 小字跟随，不丢单位信息。
- 卡片高度 68dp、列距 16dp、行距 12dp、一屏 12 道等既有版式约束不变。
- 售完灰化规则不变：整块胶囊一起变淡。
- 不改数据模型、备份格式、网络协议，不新增依赖。

## 2. 方案设计（含取舍）

### 2.1 为什么必须配淡色胶囊底

价格取自内置背景样式「喜庆红」的 `#B32C1B`（红底红字的对比不足 3:1），而卡片底只有 15% 不透明度、挡不住背景。胶囊底把价格区域从背景里「抠」出一块 90% 白，红字落在白底上对比度约 6.2:1，既保住喜庆配色又不牺牲可读性。

- 胶囊底色不参与「菜品卡片不透明度」设置：无论店主把卡片调多透明、用哪张背景图，价格区始终可读。
- 取舍：不加胶囊时只能退回深紫/近黑等与背景无关的颜色，会丢掉店主想要的喜庆红。

### 2.2 尺寸与排版

| 项 | 值 | 说明 |
| --- | --- | --- |
| 价格列宽 | 128dp（原 100dp） | 胶囊在列内 `fillMaxWidth()`，跨卡片左右边界仍对齐 |
| 胶囊圆角 / 内边距 | 10dp / 横向 10dp、纵向 4dp | 与卡片圆角 14dp 形成层级 |
| 价格数字 | 22sp | 与菜名同级，第一眼可见 |
| 单位 | 13sp、同色 72% 透明度 | `/ 份` 跟随数字，不抢焦点 |
| 溢出 | 单行 `Ellipsis` | 极长价格（如 `¥9999.99 / 份`）不撑破列 |

价格列加宽 28dp 后菜名列约剩 170dp：本机 961dp 宽、2 列网格下，默认菜单最长 6 字（「芝士玉米鲜肉」）仍能完整显示，更长菜名继续跑马灯。

### 2.3 与售完态的关系

现有规则是「售完卡片内容整体 `alpha(0.45f)`」。价格胶囊沿用同一规则：底与文字一起变淡，售完时不会出现一块刺眼的红白胶囊。

### 2.4 配色归属

新增 `ui/theme/PriceColors.kt`（`Container` / `Content`），与 `StatusColors`、`StoreNameColors` 同构：只服务展示页价格这一处，不与全局主题色耦合，便于后续单独调色。
## 3. 接口与数据模型变化

| 位置 | 变化 |
| --- | --- |
| `ui/theme/PriceColors.kt` | 新增：价格胶囊底色 `Container = 0xE6FFFFFF`、文字色 `Content = 0xFFB32C1B` |
| `ui/display/DisplayScreen.kt` | 价格列 100dp → 128dp；价格由纯文字改为 `PriceTag` 胶囊（22sp 数字 + 13sp 单位 + 淡色底 + 省略号兜底） |

无数据模型、备份格式、网络协议变化；`PriceFormatter` 输出契约不变。

## 4. 边界与失败场景

| 场景 | 处理 |
| --- | --- |
| 整数 / 含角分价格 | `¥10` / `¥10.50`，同一胶囊渲染 |
| 极长价格（`¥9999.99 / 份`） | 单行省略号，不撑破列、不换行 |
| 单位为空白 | 只渲染数字，不留分隔符 |
| 售完 | 整块胶囊 `alpha 0.45`，与卡片其他内容一致 |
| 卡片不透明度调到 15% 或更低 | 胶囊底固定 90% 白，价格依旧可读 |
| 菜名较长 | 菜名列弹性收缩，超宽沿用跑马灯 |

## 5. 测试与验收

- 构建门禁：`assembleDebug` + `testDebugUnitTest` + `connectedDebugAndroidTest`（17 项）通过，无回归。
- 真机验收（Teclast T10）：默认喜庆红背景 + 卡片 15% 下价格清晰；`¥10 / 份`、`¥20 / 份` 显示正常且不换行、不省略；跨卡片胶囊左右边界对齐；一屏 12 道无滚动；售完卡片价格整体灰化。
- 边界验收：把某道菜价格临时改为 `¥9999.99` 检查走省略号而非撑破列。

## 6. 验证记录

- 构建与单测：2026-10-06，JDK 17 + Gradle 8.9，`assembleDebug`、`testDebugUnitTest` 通过。
- 仪表测试：Teclast T10（API 24）`connectedDebugAndroidTest` **22 项全通过**，其中新增 `DishCardTest` 5 项覆盖整数价、含角分价、空单位（只显示数字）、极长价格 `¥9999.99 / 份` 与售完态徽标。
- 真机截图：默认喜庆红背景 + 卡片 15% 不透明度下，价格胶囊为清晰的浅色块、喜庆红大字，`¥10 / 份`、`¥20 / 份` 等均单行显示、无换行无省略；跨卡片胶囊左右边界对齐；一屏 12 道无滚动；菜名（最长 6 字）完整显示，无提前跑马灯。
- 未覆盖：多分辨率 / 更窄平板的菜名列宽表现；极端价格在真机上的省略号观感（仪表测试只验证可渲染）。
